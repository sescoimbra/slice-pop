OS TEUS DADOS

Privacidade

Neste dispositivo

O teu recorde, o piso escolhido e as preferências de som e vibração ficam guardados neste navegador. Podes removê-los nas definições de dados do site do teu navegador.

Jogar livremente

Não precisas de conta para jogar. Nesta versão, o login e os rankings estão em preparação e os resultados não são enviados para uma classificação online.

Ficheiros e partilha

As fontes, imagens e sons do jogo são locais. Alguns ficheiros ficam em cache para poderes jogar offline. Se partilhares um desafio, o link inclui a pontuação e os dados necessários para repetir a mesma sequência de bolas.

Alojamento

O site é servido pelo GitHub Pages. O GitHub regista endereços IP de visitantes para fins de segurança, conforme a sua documentação.
